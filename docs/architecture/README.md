# Phittoos Architecture Diagrams

This directory contains architecture diagrams for the Phittoos Android application.

## Current V1

Location: `v1/`

Diagrams 01–05 document the current offline-first Android application, including accounting, settlement, database relationships, and security boundaries.

## Proposed V2

Location: `v2-proposed/`

Diagrams 06–10 describe a possible future shared-ledger architecture with account linking, consent, shared financial events, synchronization, and authorization.

**V2 is proposed and not implemented.**
